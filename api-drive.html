Drive viewer

Browse an account’s Drive with a key that has read permission: folders, previews and downloads. A key with write permission can also upload, create folders, rename, move and delete.

Key storage: remembered keys are stored in this browser’s local storage without encryption. Only remember a key on a device you trust. The server does not reveal a key’s name here, so you can give each saved key your own label.

The current key is kept only in memory unless you choose to remember it.
